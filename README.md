# Alejandro Espinoza

Desarrollo herramientas de software para optimizar flujos de trabajo en entornos de producción. Mi trabajo abarca aplicaciones de escritorio y web, desde la lógica de negocio hasta su compilación, distribución y mantenimiento en redes corporativas.

## Sobre mí

Trabajo en el desarrollo e implementación de herramientas internas para el área de pruebas funcionales en manufactura. La mayoría de mis proyectos parten de un problema concreto en el piso de producción y buscan concentrar en una sola pantalla información que hoy está repartida entre carpetas, servidores y sistemas distintos.

## Áreas de trabajo

- **Python:** aplicaciones de escritorio con Tkinter, automatización de tareas y procesamiento de archivos.
- **Scripting:** AutoHotkey y Batch para automatización en Windows.
- **Datos:** Excel VBA y SQL para integración y generación de reportes.
- **Web:** Flask y FastAPI, con despliegue en Render.

## Distribución de aplicaciones

- Compilación con Nuitka, PyInstaller y PyArmor.
- Instaladores y sistemas de actualización por red (LAN) con control de versiones y respaldo automático.
- Control de versiones con Git, GitHub y GitHub Actions.

## Proyectos

- **FVS Monitor:** monitoreo en tiempo real de estaciones de prueba, con estadísticas de rendimiento y trazabilidad de seriales.
- **SerialInsight:** consulta, corrección y envío de logs de pruebas funcionales, con integración a Shopfloor.
- **LogFinder:** búsqueda y filtrado de archivos de log por PPID, fecha, estado y código de proyecto.
- **GTS Tools:** monitoreo, verificación de integridad y reinicio remoto de equipos GTS.
